jira 이슈 목록과 내용을 열람하고 상태업데이트 등을 처리하는 앱을 개발합니다.

1. 구현 방식
- 런타임
Node.js (Electron 내장)
- 프레임워크
Electron
- AI 기능
@github/copilot-sdk
- UI
Vanilla HTML + CSS + JavaScript
- 빌드 도구
electron-builder
- 설정 저장
브라우저 `localStorage`
- 패키징 형식
macOS `.dmg`, Windows `.exe` (NSIS), Linux `.AppImage` 

2. jira 이슈 목록
2.1 검색 항목
2.1.1 종류 (type, select field)
- 이슈
- 맨션된 이슈
2.1.2 상태 (status, select field)
- '백로그' , '진행 중', '검토 중' 인 상태
- '테스트 요청'
- '완료'
- '전체'
2.1.3 이메일 (email, text field)
2.1.4 최대 개수 (max_num, number field)

2.2 검색 로직
2.2.1 '종류'가 '이슈'일 때
이슈 상태 == {status} && 담당자 == {email} 조건을 만족하는 
최근 이슈 최대 {max_num} 개를 가져옵니다.

2.2.2 '종류'가 '맨션된 이슈'일 때
이슈 상태 == {status} && 담당자 != {email} 
&& 댓글에서 {email} 사용자가 맨션되었지만 해당 댓글의 대댓글이 없거나 대댓글 작성자가 {email}이 아닌 상태 조건을 만족하는
최근 이슈 최대 {max_num} 개를 가져옵니다.
