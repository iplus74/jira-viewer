토큰을 비워두면 로컬에 로그인된 Copilot CLI(`copilot login`) 인증을 사용합니다. 입력 시 반드시 유효한 토큰이어야 합니다(Bad credentials 오류 시 토큰 값을 확인하거나 비워 두세요).
콤마로 구분해 여러 모델을 지정하면 앞에서부터 순서대로 시도하며, 실패 시 다음 모델로 넘어갑니다. 비워두면 기본 모델을 사용합니다.
CLI 실행 시 호출할 SKILL 이름을 지정합니다. (비워두면 기본값 jira-ai-task 사용)
지정된 폴더 하위의 issues/{오늘날짜}/view_{이슈키}.md 및 tasks/{오늘날짜}/task_{이슈키}.md 경로를 사용합니다.
토큰 및 설정은 브라우저 localStorage에 저장됩니다. 공용 PC에서는 사용 후 삭제를 권장합니다.
